# PetWatch

A PHP web app for finding missing pets. You can browse and search lost
and found pets, see them on a map, and report sightings.

Built with PHP (MVC), MySQL, JavaScript and Leaflet for the map.
Made for the Client Server Systems module at the British University of
Bahrain. AI was used to help develop it.

To run it, put the folder in XAMPP's htdocs, create a database called
petwatch, and open index.php.
